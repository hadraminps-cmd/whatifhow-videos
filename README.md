# Cell Block 3D style kit

A style for the faceless-shorts skill: true prison breaks, heists and cons, with flat 2D cartoon people in vivid 3D sets.
Install: copy `styles/cell-block/` into the faceless-shorts skill folder's `styles/`, then run
`bash <skill>/scripts/new_video.sh cell-block <short-name>`. Read `styles/cell-block/STYLE.md` first.
